# Gestion de Clinique ALBAHJA

## Description
Application de gestion hospitalière "Clinique ALBAHJA" conçue pour centraliser et optimiser les opérations administratives, médicales et pharmaceutiques. Elle offre des fonctionnalités adaptées aux administrateurs, médecins, pharmaciens et patients, avec une interface intuitive et sécurisée.

## Fonctionnalités
### Côté Client (Patients)
- Inscription et connexion simplifiées.
- Accès à une carte interactive de l’hôpital.
- Informations sur les hôtels à proximité.
- Gestion des comptes (modification des informations, réinitialisation de mot de passe).
- Prise de rendez-vous.
- Génération de factures et consultation des services disponibles.

### Côté Administration
- Gestion des médecins et pharmaciens (ajout, modification, suppression).
- Supervision globale des activités.

### Côté Médecins
- Ajout, consultation, modification et suppression des dossiers patients.
- Gestion des rendez-vous et antécédents médicaux.

### Côté Pharmaciens
- Gestion de la base de données des médicaments (ajout, modification, suppression).
- Suivi des quantités et notifications en cas de rupture de stock.
- Recherche dynamique des médicaments.

## Technologies Utilisées
- **Java**: Langage principal pour le développement robuste.
- **Swing**: Bibliothèque graphique pour les interfaces utilisateur.
- **JDBC**: Connectivité avec la base de données MySQL.
- **MySQL**: Base de données relationnelle.
- **XAMPP**: Environnement de développement local (Apache, MySQL, phpMyAdmin).
- **IntelliJ IDEA**: Environnement de développement intégré.

## Prérequis
- Java JDK 8 ou supérieur.
- MySQL Server (via XAMPP ou indépendant).
- IntelliJ IDEA.
